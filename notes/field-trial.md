# Field trial (P4)

Ghi chú khi dùng thật 20–30 mặt hàng ở quầy.

## Setup nhanh (máy dev)

1. `flutter run -d linux` (hoặc `-d chrome` / điện thoại)
2. Màn trống → **Nạp dữ liệu demo** (hoặc Cài đặt → Nạp dữ liệu demo)
3. Bật **Chữ lớn** / **Tương phản cao** nếu cần
4. Xuất CSV backup một lần (icon sao lưu)

## Checklist seed thật ở quầy

- [ ] ~20–30 SKU (≈2/3 có barcode, ≈1/3 cân ký)
- [ ] 2–4 nhà cung cấp
- [ ] Xuất CSV backup trước khi dùng hàng ngày
